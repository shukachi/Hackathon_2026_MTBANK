# Экономическое обоснование — «Moby Family»

> ⚠ **Допущения для демо-расчёта, требуют валидации реальными данными банка перед защитой.** Все числа ниже — модельные допущения для демонстрации логики расчёта (оборот, остатки, доля продуктов, ставки), а не фактические показатели МТБанка. Формат итоговой таблицы — по слайду 12 презентации банка («Экономика: что нужно показать»).

---

## 1. Допущения

### 1.1 Оборот и остатки по возрастным группам (раздельно)

| Параметр | Дети 7–13 лет | Подростки 14–17 лет |
|---|---|---|
| Средний месячный оборот по карте (оценка, BYN) | 100 (диапазон допущения 50–150) | 300 (диапазон допущения 150–400) |
| Средний остаток на карте (оценка, BYN) | 15 | 35 |

### 1.2 Структура семьи в программе (оценка состава активных Family-профилей)

| Состав семьи в программе | Доля семей (оценка) | Оборот семьи/мес (BYN) |
|---|---|---|
| Только ребёнок 7–13 | 50% | 100 |
| Только подросток 14–17 | 30% | 300 |
| Ребёнок 7–13 + подросток 14–17 | 20% | 400 |

**Блендированный средний оборот по семье** = 0,5×100 + 0,3×300 + 0,2×400 = 50 + 90 + 80 = **220 BYN/мес**.

**Блендированный средний остаток по семье** (карта + остаток в цели накопления, оценка 25% семей держат остаток в цели ~120 BYN): 0,5×15 + 0,3×35 + 0,2×50(оба остатка) + 0,25×120 (взвешенный эффект накопления) ≈ **150 BYN** (округлённая оценка для расчёта дохода от остатков).

### 1.3 Прочие допущения

| Допущение | Значение (оценка) |
|---|---|
| CAC — стоимость привлечения семьи | 25 BYN (маркетинг + операционные расходы на онбординг одной семьи; фича встроена в существующий Moby, отдельной инфраструктуры не требует) |
| Эффективная ставка дохода банка от оборота (interchange-доход, нетто) | 1,6% от оборота |
| Чистая процентная маржа банка по остаткам (годовая) | 3,5% годовых |
| Партнёрские выплаты банку (реферальная/лояльностная комиссия от партнёров) | 0,9 BYN/семью/мес (фиксированная оценка) |
| Доля семей, покупающих доп. продукт (накопительный продукт/страхование ребёнка) | 25% |
| Маржа банка с одной продажи доп. продукта/мес (в пересчёте на месяц) | 8 BYN/мес на семью, купившую продукт |
| Ставка кешбэка/манибэка, финансируемая банком, от оборота | 1,5% от оборота |
| Операционные расходы на поддержку фичи/мес на семью | 0,3 BYN (минимальны — фича внутри существующего Moby, не отдельный продукт) |

## 2. Доходы банка в месяц на семью

| Источник дохода | Расчёт | Сумма (BYN/мес) |
|---|---|---|
| Оборот по картам (interchange) | 220 BYN × 1,6% | 3,52 |
| Доход от остатков (NIM) | 150 BYN × 3,5% / 12 | 0,44 |
| Партнёрские выплаты | фиксированная оценка | 0,90 |
| Маржа доп. продуктов (ожидаемое значение) | 25% × 8 BYN | 2,00 |
| **Итого доход банка/мес** | | **6,86 ≈ 6,9** |

---

## 3. Расходы банка в месяц на семью

| Статья расходов | Расчёт | Сумма (BYN/мес) |
|---|---|---|
| Бонусы/кешбэк | 220 BYN × 1,5% | 3,30 |
| Операционные расходы на поддержку | фиксированная оценка | 0,30 |
| **Итого расходы банка/мес (без амортизации CAC)** | | **3,60** |

CAC (25 BYN) — разовая, не ежемесячная статья; учитывается отдельно в расчёте срока окупаемости.

## 4. Итоговая таблица (формат слайда 12 презентации банка)

| Статья | Сумма |
|---|---|
| Стоимость привлечения семьи (CAC) | 25 BYN |
| Расходы на бонусы/кешбэк (на семью в месяц) | 3,6 BYN |
| Доход банка (на семью в месяц) | 6,9 BYN |
| Срок окупаемости = CAC / (доход − расходы) = 25 / (6,9 − 3,6) = 25 / 3,3 | **≈ 7,6 месяца** |

## 5. Чувствительность

Срок окупаемости чувствителен в первую очередь не к обороту (рост оборота пропорционально увеличивает и interchange-доход, и кешбэк-расход, которые частично компенсируют друг друга), а к **доле семей, покупающих дополнительный продукт** — это чистая маржа без сопоставимого увеличения расходов:

- При доле семей с доп. продуктом **25%** (базовый сценарий): доход 6,9 BYN/мес, срок окупаемости ≈ **7,6 мес**.
- При росте доли до **40%** (например, за счёт целевого предложения накопительного продукта подросткам через access-request): доход доп. продуктов = 0,40 × 8 = 3,2 BYN → итоговый доход = 3,52 + 0,44 + 0,90 + 3,2 = 8,06 BYN/мес → срок окупаемости = 25 / (8,06 − 3,6) = 25 / 4,46 ≈ **5,6 мес**.
- При снижении CAC с 25 до 15 BYN (за счёт органического привлечения внутри существующей базы Moby, без внешнего маркетинга) срок окупаемости при базовом сценарии сокращается до 15 / 3,3 ≈ **4,5 мес**.

Вывод: экономика продукта устойчива даже при консервативных допущениях (окупаемость в пределах года на семью), а два управляемых банком рычага — доля кросс-продаж доп. продуктов и канал привлечения (внутренняя база vs внешний маркетинг) — дают прямой путь к ускорению окупаемости без необходимости поднимать ставку кешбэка или комиссии.

## 6. LTV-аргумент (нефинансовый, но ключевой для защиты)

Приведённый расчёт — только прямая месячная экономика пакета. Отдельный и более важный для банка долгосрочный эффект — **будущий взрослый клиент**: подросток, выросший в экосистеме Moby с собственной картой, историей квестов и накоплений, с высокой вероятностью не уходит в другой банк при достижении 18 лет и продолжает пользоваться уже привычным приложением как основным. Этот эффект не включён в расчёт срока окупаемости выше (отсутствуют надёжные данные для количественной оценки), но является частью аргумента Win-Win из `docs/product-canvas.md` и презентации банка (слайд 11, 13).
